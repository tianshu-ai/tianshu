# Local Knowledge Base

Place any files here and they will be automatically indexed into your wiki.

Supported formats:
- Text: `.md`, `.txt`, `.rst`, `.csv`, `.json`, `.yaml`, code files
- Documents: `.pdf`
- Audio: `.mp3`, `.wav`, `.m4a`, `.ogg`, `.flac`
- Video: `.mp4`, `.mkv`, `.webm`, `.mov`
- Images: `.png`, `.jpg`, `.gif`, `.webp`

Trigger indexing via `wiki_kb_scan` in a chat session.
Indexed knowledge appears in your wiki under the `knowledge/` section.
